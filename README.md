# Cotizagro

Proyecto de **CLI** que muestra un resumen de los **precios de hacienda bovina en Argentina**, agrupados por:

- Destino (invernada o faena).
- Categoría y peso del animal.

## Funcionamiento Básico

```
1. Recolector -> Obtiene los precios de la fuente una vez por día y los guarda en un archivo JSON.

2. Servidor -> Entrega los datos del JSON cuando el cliente lo solicita.

3. Cliente -> Muestra los datos que le entrega el servidor en consola en un formato simple.
```
